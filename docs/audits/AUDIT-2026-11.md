## Checked and clean

- Command injection: every process is an argv list; data reaches `sh`/`bash` only as positional `$1..$3`; `Keys.js` clamps steps and fixes verbs; the loopback `q()` escape holds against hostile values (tested); `ScopeFeed` names are shape-checked.
- Uninstall paths: plugin id regex, absolute paths, cache folder named after the plugin, `rmtree` refuses links, the loopback link is removed only when it is exactly Orbit's.
- The other ANC parsers (Apple, Bose, EarFun, Haylou, Moondrop, 1MORE, Oppo, Samsung, Huawei params, Sony frame decode): indexes guarded, loops always advance.
- Performance: OrbitPhysics, RadarClock, HoldRing, PolarScope, ScopeModel, Starfield, ChargeBeam/EnergyBeam and OrbitDaemonData timers are all gated; FrozenBlur is `live: false`; Loaders gated; canvases repaint only on change; no polling process; `orbit_anc.py` select has no busy loop.
- Network: none. Logging: only `Log.js` codes through `Redact.text`. Sockets closed in `finally`; the helper leaves when stdin closes.

## Left for the owner

- `diagnostics/Gather.js` `wl-copy --sensitive` keeps serving the copied report after the shell exits (that is how a Wayland copy works). It bends "no process outlives the shell"; accept it or say so in the README privacy section.
- `components/battery/BatterySessions.js`: the salt sits in the same `history.json` as the hashes, so the hash stops cross-file linking but not identification (~2^24 guesses with a known vendor prefix). Nothing runs it yet (logic only); decide before wiring it, and the cache file is outside "memory or DMS's settings".
