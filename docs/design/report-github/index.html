Orbit · NAK-539 · The GitHub mark beside "Copy report"

The anonymous report row of Settings, "Reset & help", before and after. After: the row approved on Sands (D453, the single model for every plugin), as is, in Orbit's settings. The GitHub mark is always there, 8 px to the right of "Copy report": it opens a new issue for Orbit, where the report is pasted. Once the report is copied the mark takes the primary colour, so the next step shows itself. Switch "Clipboard tool" to "Missing" to see the guided message. Every state is also drawn side by side under the panel.

Why it is not generic: no toast and no green tick. "Copied" is marked by the dotted orbit of Orbit's own sky, drawn at the foot of the button, and the next step lights up beside it like a body entering the light.
